# مراتب الدين — حديث جبريل (إسلام حجازي · أبو معاذ)

إنتاج ريل 9:16 ونسخة يوتيوب 16:9 من 3 مقاطع، ببيئة سحابية بلا ماك.

- `pipeline/` — التفريغ (sherpa-onnx whisper large-v3، جملة جملة)، قص الشخص (u2net_human_seg + فرق عن خلفية مرجعية + تثبيت زمني)، بيانات القص والكابشن (`build_data.py` → `data.json`)، الصوت.
- `engine/` — محرّك الرسم (`compose.html`: الخلفية، الكابشن، أركان الإسلام، المراتب، الانتقالات) و`render.js` (يرسم بكروميوم ويضخ لـffmpeg) و`cover.js`.
- `output/` — الترجمة `.srt`، النص `.txt`، الغلاف والثمبنيل.

ملفات الفيديو النهائية ما انرفعت للمستودع (حجمها كبير) — تسلّمت بالمحادثة.
